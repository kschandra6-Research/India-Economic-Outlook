# India Economic Outlook Dashboard

`index.html` is the static-hosting entry point. It is a self-contained page with inline styling, charts, analysis, source data, and interactions; it requires no build step, server-side code, external libraries, fonts, or API credentials. `india-economic-outlook-dashboard.html` is the descriptive copy used for local preview.

To publish, upload `index.html` to the document root of a static web host, or place this folder in a repository and configure the host to publish the folder containing `index.html`. No environment variables or backend services are required.

The page includes all 17 forecast entries and 12 reference titles from the supplied workbook. Calculated comparisons are labelled as unweighted, the Asian Development Bank range is preserved in point-to-point analysis, and incomplete source coverage is shown explicitly.
